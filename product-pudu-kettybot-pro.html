Overview

About the PUDU KettyBot Pro

KettyBot Pro is an autonomous passenger guidance robot designed for high-footfall environments. It assists visitors by providing directions, displaying information, and guiding them to destinations such as gates, counters, shops, or departments.
Key Features

What Sets the PUDU KettyBot Pro Apart

Autonomous Navigation

Safely navigates complex indoor spaces using LiDAR and vision sensors.

Interactive Touch Display

Large screen displays maps, directions, and announcements.

Multilingual Assistance

Supports multiple languages for diverse passenger groups.

How It Works

Core Functions

Route Guidance

Information Assistance

Provides real-time facility and service information.

Technical Details

Design & Hardware
